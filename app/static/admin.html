部署提示

  • 访问口令与后台口令在 .env 的 ACCESS_PASSWORD / ADMIN_PASSWORD 中设置，改后重启容器生效。两者务必不同。
  • 公网请套 NAS 反向代理并开启 HTTPS，同时把 COOKIE_SECURE 设为 1。
  • 预设里的模型名称只是常见值，以各家官方文档为准，可在上面直接改。
  • 配置文件保存在 ./data/config.json，内含 API Key 明文，别把这个目录共享到公网。
  • 照片与点评结果不落盘；容器重启后统计清零。
